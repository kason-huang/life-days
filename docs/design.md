# 日子有数：设计与行为

## 产品范围

个人离线使用，Android 优先，Flutter 共用逻辑与界面，保留未来 iOS 工程。电脑通过离线 HTML 编辑器生成 JSON，再将文件传入手机导入；当前不提供联网同步、提醒或桌面组件。

## 界面

采用 A「温暖手账」：暖白底、陶土色强调、置顶日子大卡片、事件列表。首页支持全部、纪念日、倒计时和归档筛选。详情提供日期与规则、备注、编辑、置顶、归档恢复和删除。空列表可直接创建事件。

- `prototypes/days-prototype.html`：基础交互与 A/B/C 三种视觉方案。
- `prototypes/lunar-birthday-prototype.html`：农历生日设置、双历换算与规则预览。
- 原型中的示例日期固定在 2026-11-06；数据仅存在于当前页面内存。原型用于设计评估，手机应用按实际日期计算并持久保存。

## 日期语义

- 纪念日从原始日期持续累计，默认起始日为 0，可包含当天；跨周年不归零。
- 倒计时不重复、按周或按年；不重复事件过期后保留并显示已过去的天数。
- 生日是每年重复的倒计时；生日当天显示祝福，次日计算下一年生日。默认不显示年龄，开启后须填写实际出生年份。
- 公历 2 月 29 日在非闰年可按 2 月 28 日或 3 月 1 日计算。
- 农历输入支持年份 1900–2100，月份和日期选项随年份自动变化，闰月、三十均须真实存在。
- 农历年生日每年换算公历日期；按实际日期差显示剩余天数。农历正月前的腊月生日仍属于上一农历年。
- 闰月生日可选优先当年同名闰月、没有时用普通月，或始终普通月；普通月生日不在闰月额外重复。
- 农历三十遇小月可选本月廿九或下月初一；即使跨到次年正月，年龄仍按原始生日所属农历年计算。
- 农历纪念日累计实际公历天数，下个周年按农历计算。农历事件不支持每周重复。

## 数据与兼容

本地 JSON 版本 3，显式记录类型、历法和规则。农历事件同时保存原始公历日期与农历年月日，导入时校验一致性；闰月用负月份表示。旧 v1/v2 数据升级前保留原始备份，已有事件保持原历法。导入先预览并校验，出错时阻止整批导入；同名称、日期、类型、重复规则和历法的记录跳过，避免覆盖个人修改。

Android 0.3.0 包名与签名延续旧版，可覆盖安装。应用中的农历换算使用离线 Dart 库，电脑编辑器使用浏览器内置农历支持；不依赖网络服务。
